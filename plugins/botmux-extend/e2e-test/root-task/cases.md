# 根任务生命周期

覆盖命令：`init`、`show`、`start`、`status`、`output`。只操作根任务，不建工作群。

| 编号 | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| R1 | 创建根任务并写入全部字段 | `init --title --desc --criteria --priority 高 [--from 派发人]`，再 `show` | 成功；负责人是执行测试的 bot，状态进行中，优先级高，当前进展为 `[MM-DD HH:mm] 进行中：创建任务`；没有父任务、没有工作群、子任务数 0；设置了派发人时 `dispatcher.open_id` 等于派发人 |
| R2 | 不传优先级和派发人 | `init` 不带 `--priority`、`--from`，会话发起人为空 | 优先级为"中"；派发人为空 |
| R3 | 派发人取会话发起人 | `init` 不带 `--from`，会话发起人设为派发人 | 派发人等于会话发起人（未设置派发人时跳过） |
| R4 | 对进行中的任务执行 start | `start` | 成功，状态仍是进行中 |
| R5 | 根任务改为阻塞 | `status 阻塞 --note <原因>` | 成功，`notified` 为 false（没有工作群）；当前进展为 `… 阻塞：<原因>` |
| R6 | 对阻塞的任务执行 start | `start` | 成功，状态仍是阻塞 |
| R7 | 阻塞后恢复进行中，不带说明 | `status 进行中` | 成功，`notified` 为 false；当前进展为 `… 进行中：继续处理` |
| R8 | 写入产出 | `output <内容>`，再 `show` | 成功；产出等于写入的内容 |
| R9 | 没有子任务的根任务直接完成 | `status 已完成 --note <说明>` | 成功，`notified` 为 false；状态已完成 |
| R10 | 对已完成的任务执行 start | `start` | 成功，状态仍是已完成 |
